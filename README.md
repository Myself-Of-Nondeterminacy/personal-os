# personal-os

格雨的个人操作系统仓库：把 Obsidian / Notion / GitHub 的模板、脚本和可复用流程版本化。

分工：

- Obsidian：长期知识、复盘、读书笔记。
- Notion：项目、任务、数据库、状态追踪。
- GitHub：模板、脚本、流程定义，不存放版权书籍原文。

## 目录

- `books/`：书籍元数据与阅读协议（不放 EPUB/PDF 原文）
- `templates/`：Obsidian/Notion 可复用模板
- `scripts/`：本地工具脚本，例如 EPUB 元数据提取

## 当前书籍

- 当下的力量（白金版） — 埃克哈特·托利
- 掌控习惯（新版） — 詹姆斯·克利尔
